Рівень 17: Інтеграція FastAPI з Google API

Google пропонує величезну екосистему потужних API, які можуть значно розширити функціонал вашого застосунку, але їх інтеграція вимагає уважного налаштування автентифікації. Ми зануримося у світ Google API та навчимося інтегрувати їх із FastAPI.

Ви дізнаєтеся про ключові концепції Google Cloud Console, такі як сервісні акаунти для серверної автоматизації, OAuth2 для доступу від імені користувача та області доступу (scopes). Ми освоїмо використання бібліотеки google-api-python-client для взаємодії з Google Sheets API (читання та запис даних) та Google Drive API (завантаження файлів, створення папок), забезпечуючи при цьому неблокуючу роботу FastAPI за допомогою asyncio.to_thread.

Також розглянемо пряме використання httpx для простіших REST API, таких як Google Maps Geocoding, та питання обробки помилок і лімітів при роботі з сервісами Google.

Що таке Google API і навіщо вони потрібні?

Інтеграція з Google API дозволяє швидко додати до проєкту складну функціональність, розробка якої з нуля була б дуже дорогою та довгою.

Взаємодія з Google API будується на кількох ключових концепціях:

  • аутентифікація та авторизація: доступ до API захищений. Ви повинні довести, що ваш застосунок має право виконувати ті чи інші дії.
  • сервісний акаунт (Service Account): спеціальний "нелюдський" акаунт Google, який представляє ваш застосунок (бота, сервер). Використовується для автоматизації завдань від імені застосунку, а не конкретного користувача.
  • OAuth2: стандарт авторизації, що використовується для отримання доступу до даних користувача з його дозволу.
  • токени доступу (Access Tokens): тимчасові ключі (access_token, refresh_token), які ваш застосунок використовує для автентифікації запитів до API.
  • scopes (області доступу): визначають, на які саме права робить запит ваш застосунок (наприклад, .../auth/spreadsheets.readonly — лише читання таблиць, .../auth/drive — повний доступ до Drive).

Налаштування проєкту в Google Cloud Console

Перш ніж писати код, необхідно налаштувати проєкт у Google Cloud.

Основні кроки:

  1. Створити проєкт: перейдіть до Google Cloud Console і створіть новий проєкт.
  2. Увімкнути потрібні API: у розділі "API та сервіси" -> "Бібліотека" знайдіть та увімкніть необхідні API (наприклад, "Google Sheets API", "Google Drive API").
  3. Налаштувати автентифікацію:
    • для автоматизації (сервер-сервер): створіть сервісний акаунт у розділі "IAM та адміністрування" -> "Сервісні акаунти". Завантажте JSON-файл із ключами — це ваш "пароль".
    • для доступу до даних користувачів: створіть облікові дані OAuth 2.0 (Client ID) у розділі "API та сервіси" -> "Облікові дані".
  4. Надати доступ: якщо ви використовуєте сервісний акаунт, не забудьте "поділитися" з ним вашим Google-документом (таблицею, папкою на Диску), вказавши email сервісного акаунта в налаштуваннях доступу, ніби це звичайний користувач.

Аутентифікація

Для серверних завдань (наприклад, FastAPI-бекенд, що працює з вашою таблицею) найчастіше використовується сервісний акаунт.

Бібліотека Google для Python:

pip install google-api-python-client google-auth-httplib2 google-auth-oauthlib

Приклад отримання облікових даних із JSON-файлу:

from google.oauth2 import service_account

# Шлях до завантаженого JSON-файлу
SERVICE_ACCOUNT_FILE = 'path/to/your-service-account.json'
# Області доступу (scopes), які потрібні вашому застосунку
SCOPES = ['https://www.googleapis.com/auth/spreadsheets', 'https://www.googleapis.com/auth/drive']

# Створюємо об'єкт credentials
credentials = service_account.Credentials.from_service_account_file(
    SERVICE_ACCOUNT_FILE,
    scopes=SCOPES
)

Цей об'єкт credentials буде використовуватися для аутентифікації ваших запитів до Google API.

Робота з Google Sheets API

Читання даних із таблиці:
Бібліотека google-api-python-client є синхронною. В асинхронному FastAPI її слід запускати в окремому потоці, щоб не блокувати event loop.

from googleapiclient.discovery import build
import asyncio

# credentials — із попереднього слайда
# SPREADSHEET_ID — ID вашої таблиці з URL

async def read_sheet():
    # Створюємо клієнт для Google Sheets API
    service = build('sheets', 'v4', credentials=credentials)
    # Виконуємо синхронний код в окремому потоці
    result = await asyncio.to_thread(
        service.spreadsheets().values().get(
            spreadsheetId=SPREADSHEET_ID,
            range='Sheet1!A1:C10' # Діапазон комірок
        ).execute
    )
    return result.get('values', [])

Додавання рядків до таблиці:

async def append_to_sheet(values: list):
    service = build('sheets', 'v4', credentials=credentials)
    body = {'values': values} # values — це список списків, [[row1_colA, row1_colB], [row2_colA, ...]]
    await asyncio.to_thread(
        service.spreadsheets().values().append(
            spreadsheetId=SPREADSHEET_ID,
            range='Sheet1!A1', # Почати пошук порожнього рядка з A1
            valueInputOption='RAW', # Дані вставляються як є
            insertDataOption='INSERT_ROWS',
            body=body
        ).execute
    )

Робота з Google Drive API

Аналогічно до Sheets, для Drive використовується той самий google-api-python-client.

Завантаження файлу:

from googleapiclient.http import MediaFileUpload

async def upload_file_to_drive(file_path: str, file_name: str):
    service = build('drive', 'v3', credentials=credentials)
    # Описуємо метадані файлу
    file_metadata = {'name': file_name}
    # Описуємо медіа-контент для завантаження
    media = MediaFileUpload(file_path, mimetype='application/pdf')

    # Запускаємо завантаження в окремому потоці
    file = await asyncio.to_thread(
        service.files().create(
            body=file_metadata,
            media_body=media,
            fields='id' # Які поля повернути у відповіді
        ).execute
    )
    return file.get('id')

Створення папки:

async def create_drive_folder(folder_name: str):
    service = build('drive', 'v3', credentials=credentials)
    folder_metadata = {
        'name': folder_name,
        'mimeType': 'application/vnd.google-apps.folder'
    }
    folder = await asyncio.to_thread(
        service.files().create(body=folder_metadata, fields='id').execute
    )
    return folder.get('id')

Робота з Google Maps API

Для простіших REST API від Google, таких як Maps Geocoding, зручніше використовувати httpx напряму, оскільки це природно асинхронний підхід.

Геокодування (перетворення адреси на координати):

import httpx
from fastapi import HTTPException

# GOOGLE_MAPS_API_KEY — ваш ключ API, що зберігається в .env
async def geocode_address(address: str):
    url = "https://maps.googleapis.com/maps/api/geocode/json"
    params = {"address": address, "key": GOOGLE_MAPS_API_KEY}

    async with httpx.AsyncClient() as client:
        response = await client.get(url, params=params)
        if response.status_code != 200:
            raise HTTPException(status_code=502, detail="Помилка API геокодування")

        data = response.json()
        if not data.get("results"):
            raise HTTPException(status_code=404, detail="Адресу не знайдено")

        location = data["results"][0]["geometry"]["location"]
        return location # -> {"lat": ..., "lng": ...}

Цей підхід ідеально вписується в асинхронну природу FastAPI.

Обробка помилок та лімітів

Під час роботи з Google API ваш код має бути готовим до помилок.

Основні типи помилок:

  • мережеві помилки: таймаути, проблеми з DNS (обробляються httpx.RequestError).
  • HTTP-помилки: 4xx (невірні права, перевищено квоту) та 5xx (проблеми на стороні Google).

Стратегії обробки:

  • використовуйте try...except: завжди обгортайте виклики API в блоки обробки винятків.
  • перевіряйте статус-код: аналізуйте код відповіді та повертайте клієнту зрозумілу помилку (HTTPException).
  • реалізуйте повторні спроби (Retry): для помилок 429 (Too Many Requests) та 5xx корисно почекати деякий час і повторити запит (патерн Exponential Backoff).
  • кешуйте результати: щоб зменшити кількість запитів і не перевищувати ліміти.

Приклад інтеграції: запис даних у Google Sheets з FastAPI

from fastapi import FastAPI, Depends, HTTPException
from pydantic import BaseModel
# ... (імпорти та налаштування credentials з попередніх слайдів) ...

app = FastAPI()
SPREADSHEET_ID = "ваш_id_таблиці"

class UserLead(BaseModel):
    name: str
    email: str
    phone: str

@app.post("/leads/submit")
async def submit_lead(lead_data: UserLead):
    # Готуємо дані для запису (один рядок, три стовпці)
    values_to_append = [[
        lead_data.name,
        lead_data.email,
        lead_data.phone
    ]]
    body = {'values': values_to_append}

    # Викликаємо асинхронну функцію для додавання даних
    await append_to_sheet(body)

    return {"status": "success", "message": "Дані успішно додано до таблиці."}

async def append_to_sheet(body: dict):
    # Ця функція може бути в окремому сервісному шарі
    try:
        service = build('sheets', 'v4', credentials=credentials)
        await asyncio.to_thread(
            service.spreadsheets().values().append(
                spreadsheetId=SPREADSHEET_ID,
                range='Leads!A1', # Записувати в аркуш "Leads"
                valueInputOption='RAW',
                body=body
            ).execute
        )
    except Exception as e:
        # Тут має бути належне логування помилки
        raise HTTPException(status_code=500, detail="Помилка під час запису в Google Sheets.")
