# 🏆 Проект "Telegram/ChatGPT"
Проект представляє собою інтерактивний Telegram-бот на базі python-telegram-bot, що поєднує в собі освітні квізи, рекомендаційну систему медіа та можливості штучного інтелекту для аналізу зображень.

# 🎮 Функціональні можливості та Меню бота

### 1. *"Випадковий факт"*
Телеграм-бот обробляє команду /random.
При обробці команди він надсилає заздалегідь підготовлене зображення
та робить запит до ChatGPT із заздалегідь підготовленим промптом.
Відповідь ChatGPT передає користувачеві.
До повідомлення прикріплена кнопка "Закінчити", натискання на яку
працює так само, як команда /start.
І кнопка "Хочу ще факт", натискання на яку
працює так само, як команда /random


### 2. *"ChatGPT інтерфейс"*
Телеграм-бот обробляє команду /gpt.
При обробці команди він надсилає заздалегідь підготовлене зображення
та робить запит до ChatGPT, передаючи йому
текст отриманого повідомлення. Відповідь ChatGPT передає користувачеві текстовим повідомленням


### 3. *"Діалог з відомою особистістю"*
Телеграм-бот повинен обробляти команду /talk.
При обробці команди бот надсилає заздалегідь підготовлене зображення та
пропонує вибір з декількох відомих особистостей,
використовуючи кнопки. При натисканні кнопки встановлюється промпт обраної особистості.
Подальші текстові повідомлення від користувача потрібно передавати ChatGPT та
повертати його відповіді користувачеві.
До них прикріплена кнопка "Закінчити", натискання на яку
працює так само, як команда /start


### 4. *"Квіз"*
Телеграм-бот обробляє команду /quiz.
Багатопрофільність: Питання з IT, математики, біології та географії.
Динамічний інтерфейс: Використання інлайн-кнопок, які автоматично видаляються після відповіді, щоб не захаращувати історію чату.
Рівні складності: Система автоматично відстежує ваш прогрес.
При обробці команди бот надсилає заздалегідь підготовлене зображення
та пропонує вибір з декількох тем, використовуючи кнопки.
Після вибору теми, передати запит ChatGPT і, отримавши питання квізу, передати його
користувачеві. Наступне текстове повідомлення користувача вважається відповіддю.
Його потрібно передати ChatGPT та отримати результат. Результат передати користувачеві
з можливістю задати ще питання на ту ж тему, змінити тему або закінчити квіз, за допомогою кнопок.
Бот також веде рахунок правильних відповідей та
відображає разом із черговим результатом


### 5. *"Рекомендації щодо фільмів та книг"*

Бот пропонує вибрати категорію рекомендацій: фільми, книги, музика.
Після вибору категорії бот запитує жанр.
Після отримання, формує запит та запитує у ChatGPT рекомендації 
та надсилає їх користувачеві.
До них прикріплені кнопки:
"Не подобається", яка робить вибраний твір нецікавим. Натискання на
кнопку генерує нову відповідь, враховуючи всі нецікаві твори, введені користувачем.
"Закінчити", натискання на яку працює так само, як команда /start.


### 6. *"Розпізнавання зображень"*

Бот приймає від користувача зображення та передає його ChatGPT.
ChatGPT визначає, що знаходиться на зображенні та описує в текстовому вигляді.
Відповідь передаєтсья користувачеві в текстовому повідомленні.


## ⚙️ Збереження
Проєкт використовує PicklePersistence для того,
щоб навіть після перезапуску сервера бот пам'ятав,
на якому питанні зупинився користувач та скільки балів він встиг заробити.


## 🏗️ СТРУКТУРА ПРОЄКТУ
Проєкт організований за модульним принципом, де кожен файл відповідає за окрему логіку:
```pyhton
.
├── bot.py                          # Головна точка входу. Ініціалізація та запуск бота.
├── credentials.py                  # Конфігурація: завантаження токенів та налаштувань.
├── db.py                           # Робота з даними: збереження прогресу квізу та статусів.
├── gpt.py                          # Підключення та налаштування ChatGPT
├── util.py                         # Допоміжні інструменти: форматування тексту, логування.
│
├── handlers/
│   ├── common.py                   # Відповідає за головне меню бота та пункт рандом.
│   ├── gpt_handler.py              # Відповідає за ChatGPT інтерфейс.
│   ├── image_handler.py            # Розпізнавання зображень.
│   ├── quiz_handler.py             # Логіка квізів: обробка питань, перевірка відповідей.
│   ├── recommendation_handler.py   # Рекомендації щодо фільмів, музики та книг.
│   ├── talk_handler.py             # Діалог з відомою особистістю.
│
├── resources/                      # Ресурси проекта (картинки, повідомлення та промпти).
│   ├── images/
│   ├── messages/
│   ├── prompts/
```
## 📋 ПОЧАТОК РОБОТИ

### 1. Клонування репозиторію
```bash
git clone https://github.com/KiLaVme/Telegram-ChatGPT.git
cd Telegram-ChatGPT
```
### 2. Встановлення залежностей
```bash
pip install -r requirements.txt
```
### 3. Налаштування середовища
Створіть файл .env у кореневій директорії та додайте туди ваші ключі:
```pyhton
#Фрагмент коду
TELEGRAM_BOT_TOKEN=ваш_токен_від_botfather
OPENAI_API_KEY=ваш_ключ_openai
```
### 4. Запуск
```bash
python main.py
```
